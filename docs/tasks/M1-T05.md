## Lesson
### Why this matters in the project
CI (M1-T08) will run exactly these targets, so "green locally" and "green in CI" mean the same thing. Later targets (`make chaos SEED=…`, `make proto`, `make reset`) grow from this file.

### Mental model
A Makefile is a list of **targets**: `name: dependencies` followed by **tab-indented** shell commands. `make test` runs the `test` recipe. `.PHONY` marks targets that are commands, not files, so make never skips them because a file called `test` exists.

### Key concepts
- Recipe lines **must start with a TAB**, not spaces (`missing separator` error otherwise).
- `./...` = this package and everything below it.
- `go test -race`: builds with the race detector; slower, catches data races (matters for `node/` in M5). Needs cgo; on macOS that works out of the box.
- `-count=1` disables the test cache so tests actually rerun.
- `golangci-lint run` reads `.golangci.yml` if present (added in M1-T06); without it, v2 runs its default set (errcheck, govet, ineffassign, staticcheck, unused).
- Variables: `GO ?= go` lets you override from the command line (`make GO=go1.27.3 test`).

### Worked example
```make
.PHONY: hello
hello:
	echo "hi"        # \t = a real tab
```

## Pitfalls and common mistakes
- Spaces instead of a tab in recipes.
- `make build` writing binaries into the repo root — keep them in `/bin/` (already gitignored).
- `go test` with no test files prints `[no test files]`; that is a pass.

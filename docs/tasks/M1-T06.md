## Lesson
### Why this matters in the project
The project's angle is reproducible seeds. One `time.Now()` or `rand.IntN()` in `raft/` makes a failing seed unreplayable, and that bug is invisible until you need the replay. A linter catches the easy cases at commit time; the seed-twice hash check (M4) catches the rest (`go`, `select`, map iteration), which forbidigo cannot see.

### Mental model
golangci-lint runs many linters in one pass, configured by `.golangci.yml`. **forbidigo** reports any use of an identifier matching a regex. With `analyze-types: true` it also checks the identifier's real package, so `rand.IntN` from `math/rand/v2` is caught but a method `r.IntN` on your own seeded `*rand.Rand` is not. **Exclusion rules** then switch forbidigo off everywhere except the deterministic packages.

### Key concepts
- `version: "2"` — golangci-lint v2 config format (v1 configs are rejected).
- `linters.default: standard` = errcheck, govet, ineffassign, staticcheck, unused.
- `exclusions.rules[].path-except` — the rule applies to every path **not** matching the regex; here: "ignore forbidigo outside raft/kv/wal/server/sim/chaos".
- Test files are linted too (`run.tests` defaults to true), so the ban covers `_test.go` in those packages.
- `issues.uniq-by-line: false` — otherwise only one issue per line is shown (two violations on one line hide each other).
- `formatters: gofmt` — `make lint` also fails on unformatted code.
- `golangci-lint config verify` checks the file against the schema.

### Worked example
Tested on a scratch module with golangci-lint 2.15.0: `time.Now`, `time.Since`, `rand.IntN` in `raft/` and `time.Now` in `raft/*_test.go` reported; `rand.New(rand.NewPCG(1,2)).IntN(5)` in `raft/` and `time.Now` in `node/` not reported.

## Pitfalls and common mistakes
- Banning `^rand\.` wholesale also bans `rand.New`/`rand.NewPCG`, which you need for the seeded RNG.
- Banning only `time.Now`: `time.Since`, `time.Sleep`, `time.After`, tickers read real time too.
- `time.Duration` and `time.Millisecond` are fine — types and constants, not clock reads.
- Later, a legitimate timing measurement in `sim/`/`chaos/` tests needs `//nolint:forbidigo // reason` on that line.
